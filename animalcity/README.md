# AnimalCity TV · oficina virtual

Segundo canal del dueño: sitcom animada de animales en Shorts (`@animalcity_tv`, en inglés para EE. UU.). Lo produce un equipo virtual de 7 mesas que funcionan como tareas programadas de Claude.

- `BIBLIA.md`: reparto, voces, colores, fórmula del episodio y reglas del show.
- `oficina/`: instrucciones de cada mesa (`OFICINA.md` reúne las reglas comunes; `PRODUCCION.md` es la rutina diaria).
- `pipeline/`: `sitcom.py` (personajes, decorados, render), `dialogo.py` (monta las voces), `miniaturas.py` (10 versiones y hoja de contacto), `setup.sh`.
- `registro/`: memoria del equipo (episodios, planos usados, tendencias, avisos de retención para el guionista, ideas y aprendizajes de miniaturas).
- `episodios/epNN/`: guion, líneas, escenas y miniaturas de cada episodio emitido.
- Vídeos: rama `media-animalcity` (se sobrescribe en cada subida).
