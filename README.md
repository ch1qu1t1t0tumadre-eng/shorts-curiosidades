# shorts-curiosidades

Sistema que crea y sube cada día 6 YouTube Shorts de curiosidades.
- `INSTRUCCIONES.md`: la rutina diaria completa.
- `pipeline/render.py`: monta el vídeo (voz + subtítulos + emojis).
- `temas_usados.md`: temas ya publicados.
- Rama `media`: vídeos del día (se sobrescribe a diario).
